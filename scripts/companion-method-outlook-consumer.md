# Ordinary frozen-outlook consumer

Use a compatible Companion/proxy that advertises
`augnes_read_repository_method_outlook`. This example uses the existing Node
runtime and prepared MCP SDK dependencies;
it installs nothing. The checked-out proxy is for development qualification,
not permission to replace an installed plugin.

Run the complete disposable example from the repository:

```sh
node --import tsx scripts/test-companion-method-outlook.ts
```

The test creates only disposable project data through the project owners and
work/premises through actual authenticated Companion proxy/HTTP writers. Its
explicit fixture-author direction is not an inferred live user declaration.
Stipulated effort inputs are attempt 8, mandatory verification 2, repair 3,
direct success 3/5, optional inspection cost 2, inspected success 4/5. They are
constructed stationary assumptions, not measurements or causal claims.

The consumer reads the frozen outlook and basis through the new tool. It runs
`node --check` on a known-valid task-owned module to establish this executor's
syntax-check availability. It preserves actual stdout/exit/runtime/input hash
and a deliberate availability update using existing preview/save. A preliminary
preview supplies the report's exact source binding; the final full preview/save
binds that report and the revised interpretation together. The old packet stays
reconstructable. A fresh Resume/outlook read then supports checking the candidate
module, whose actual syntax error leads to declining program execution. The
known-available control retains `inspect` after confirming support. Neither
case changes stipulated probabilities, effective direction or managed authority.

the program. The example stops on unavailable, expired, stale or uncertain
outcomes instead of refreshing and saving automatically. Its fixed branching

demand, separate-task transfer, learned rates or measured workflow benefit.
Preparation/checking effort is real but not measured against the stipulated
effort units; no total-cost improvement is established. Mandatory checks remain
mandatory. The public workflow-cost release is unchanged and independent.
