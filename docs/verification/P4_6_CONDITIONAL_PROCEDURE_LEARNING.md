# P4.6 — Conditional investigation procedure commissioning

[#1320](https://github.com/hynk-studio/augnes/issues/1320) owns this bounded
implementation under [#1214](https://github.com/hynk-studio/augnes/issues/1214),
with [#1213](https://github.com/hynk-studio/augnes/issues/1213) as a methodological
input. It is natural-language experience adaptation, not weight training,
learned retrieval, production activation, or an extension of #1150/#1319.

The hypothesis is that an extracted and locally revised investigation procedure
may improve decisions or reduce wasted work compared with a strong, freely
updated ordinary memo under the same executor, source access and task budget.
Successful delivery and deterministic software checks do not establish learning
or superiority.

## Executable method and reuse

[`method.ts`](../../scripts/conditional-procedure-learning/method.ts) versions
the authored EXTRACT, APPLY and REVISE recipes as
`conditional-investigation.v0.1`. EXTRACT asks for applicability, reusable roles,
a concrete discriminating check, result-dependent actions, stopping/non-use,
attribution and uncertainty. APPLY records an intended action and assumptions,
then a memory-use judgment and at most one explicit probe selection; a second
turn consumes its actual result and reaches a finding. REVISE returns one exact
local replacement or justified KEEP, retaining the previous version, change and
evidence. Memo generation/update permits unrestricted useful organization,
including conditional procedures and justified no further work.

[`commission.ts`](../../scripts/conditional-procedure-learning/commission.ts)
is the opt-in commissioning CLI. It freezes inputs, dispatches the fixed
sequence, records initiated turns before invocation, refuses replacement runs,
and records unavailable dependent jobs. It has no HTTP endpoint, scheduler or
default activation. Its small JSON action/replacement envelopes are local
parsing boundaries, not a durable memory schema or a required heading taxonomy
for the natural-language procedures.

[`native-turn.ts`](../../scripts/conditional-procedure-learning/native-turn.ts)
reuses normal disposable project/work preparation, selected-source construction
and comparison, packet/GuideBrief admission, the ordinary scoped native-host
adapter, receipt/proposal production, result reader and authenticated review
reader. Exact note text is checked in both the selected-source entry and
`MEMORY.md`; no silent clipping, padding or correction loss is permitted.
Fresh projects, databases, packets, threads and scoped snapshots are used for
each turn. The second application turn receives only its own first result and
coordinator observation; it does not resume a host conversation.

The worker scope remains read-only. The trusted coordinator maps a closed probe
ID to [`probe.ts`](../../scripts/conditional-procedure-learning/probe.ts),
copied into the exact disposable Git archive. It never evaluates model text as
shell code or substitutes a stronger diagnostic. Existing Canonical child,
environment, network-guard and resource-cleanup owners bound the probe.
Generated methods remain candidates. Existing disposable packet/receipt/proposal
records are reused; no new Core kind, production record, accepted state, grant,
persistent memory table or runtime permission is introduced.

Explicit operation, after separate authorization for any later study:

```text
node --import tsx scripts/conditional-procedure-learning/commission.ts freeze <absolute-evidence-directory-outside-checkout>
node --import tsx scripts/conditional-procedure-learning/commission.ts run <same-evidence-directory>
```

The first sequence is single-use. The CLI does not authorize another sequence.
`npm run test:conditional-procedure-learning` is deterministic and invokes no
model; the same test is in the ordinary unit inventory. Live execution is not
part of default tests or Local Canonical.

## Mechanisms consulted

[ExpeL](https://arxiv.org/abs/2308.10144) informs extraction of natural-language
methods from attributable experience. [ACE](https://arxiv.org/abs/2510.04618)
informs localized updates that preserve earlier material.
[GEPA](https://arxiv.org/abs/2507.19457) informs revisions grounded in actual
execution feedback. This slice adopts neither their full frameworks nor their
benchmark claims as Augnes evidence. It uses no population search, learned
selector, weight update or hidden-reasoning collection.
