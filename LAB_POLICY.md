# Lab Policy

This repository is a private Augnes perspective research lab.

It is not the canonical Augnes product repository.

Raw logs, private notes, failed experiments, and subjective evaluations stay
here.

Public changes must be promoted only as redacted fixtures, schemas, tests, or
public-safe docs.

Never copy private conversation logs or personal context directly into the
public repository.

Every experiment should record the upstream Augnes commit SHA it was based on.
