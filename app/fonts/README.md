The package metadata identifies this as Inter v20, credits the Inter Project
authors, and licenses the font under SIL Open Font License 1.1. The complete
license and attribution are included in `Inter-OFL-1.1.txt`.

Only the upright Latin `wght` variable subset is included. It covers weights
100–900, including the 600 and 650 weights used by Continuities. Italic,
static-weight, optical-size, Latin Extended, Cyrillic, Greek, and Vietnamese
files from the source package are intentionally not copied.

Inter is not used as a Hangul font. The Next local-font registration and scoped
Continuities CSS keep explicit Korean/CJK and system fallbacks for glyphs
outside this Latin asset.
